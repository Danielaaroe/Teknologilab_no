🏁 Robot Delivery Challenge

Bygg en liten robotbil som kjører autonomt og skyver en “pakke” inn i en mål-sone. Til slutt kjører vi konkurranse med poeng og flere forsøk.

👥 Team-oppsett: 3 barn + 1 voksen per lag.
⏱️ Varighet: 2 økter × 2 timer (kan også kjøres som én lang økt).

🎯 Læringsmål

  • Bygge en enkel robotbil med pusher/scoop
  • Programmere sekvens (start → kjør → stopp)
  • Justere tid/hastighet for presisjon
  • (Valgfritt) bruke sensor for stopp/treff
  • Måling og iterasjon: test → endre → test

🧰 Utstyr

  • Robotbil-kit (micro:bit buggy / Arduino bil / LEGO SPIKE / lignende)
  • Teip til bane på gulv + målebånd/linjal
  • “Pakke”: liten skumkloss/trekloss (lett å skyve)
  • Front “pusher”: papp + teip + evt. strips
  • (Valgfritt) avstandssensor/linjesensor for hard-modus
Tips: Hold det “lavterskel”: pusher foran gjør at alle får en fungerende robot uten komplisert mekanikk.

🗺️ Baneoppsett

  • Lag en rett “kjørefil” med teip (ca. 2–3 meter)
  • Marker Start
  • Plasser pakke på fast punkt (f.eks. 60 cm fra start)
  • Marker Mål-sone med 3 nivåer:
    • Bronse (stor)
    • Sølv (mellom)
    • Gull (liten i midten)

✅ Oppdraget

Robot skal:

  • Starte fra start-linje
  • Kjøre frem til pakken
  • Skyve pakken inn i mål-sonen
  • Stoppe

Enkel modus (anbefalt)

  • Kjør frem i X millisekunder
  • Stopp
  • (Valgfritt) liten sving + kjør + stopp

Hard modus (valgfritt)

  • Bruk sensor: stopp når avstand < terskel
  • Evt. linjefølger til stopp-linje

🏆 Poeng og konkurranse

  • Pakken i hvilken som helst mål-sone: 3 poeng
  • Pakken i sølv: +1
  • Pakken i gull (midt): +2
  • Raskeste vellykkede runde (minimum 3 poeng): +1
  • Pålitelighet: 2 vellykkede runder på rad: +1

Hvert lag får 3 forsøk. Beste poengsum teller.

🕒 Øktplan (2 × 2 timer)

Økt 1: Bygg + første autonome kjøring

0:00–0:10 Introduksjon + demo 0:10–0:45 Bygg bil (chassis + hjul + motor) 0:45–1:10 Lag pusher/scoop (papp + teip) 1:10–1:35 Første program: kjør frem → stopp 1:35–1:55 Test på bane (få pakken til å flytte seg) 1:55–2:00 Mini-demo: alle lag viser én kjøring

Mål: Alle lag har bil som kjører og kan skyve pakken.

Økt 2: Tuning + konkurranse

0:00–0:10 Regler + poeng 0:10–0:50 Tuning (tid/hastighet/sving) 0:50–1:30 Kvalifisering (2 forsøk per lag) 1:30–1:55 Finaler/beste forsøk + tie-break (raskeste vellykkede) 1:55–2:00 Oppsummering + premier

🧩 Startprogram (plattform-uavhengig pseudokode)

Oversett til MakeCode / Arduino / SPIKE / Scratch-blocks.

Når programmet starter: Sett motorhastighet = 50% Kjør fremover i 1200 ms Stopp Vent 500 ms

Utvidelse: legg til en liten sving før siste fremkjøring.

❓ Feilsøking

  • Kjører skjevt: senk hastighet og øk kjøretid litt; sjekk hjul sitter rett
  • Skyver ikke pakken: senk pusher nærmere gulvet; bruk lettere kloss
  • For langt/kort: juster millisekunder (små endringer, f.eks. ±100 ms)
  • Stopper ikke: sørg for “stopp motor” i slutten
